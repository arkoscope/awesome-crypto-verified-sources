# ARKOSCOPE Official Sources Registry

Maintained by **ARKOSCOPE SRL (Brussels, Belgium)**. Snapshot: **27 October 2026**. 35 records from three catalogue waves.

## Contents and languages
`sources.json` contains the project name, ticker, first-party website, followed X account, resource URLs, evidence status, evidence URL, check date and scope notes. The factual source records and notes are principally English; the directory presentation is available in EN/FR/DE/ES/NL. These are not 175 independently verified records.

## Provenance and limitations
References were gathered from first-party public pages and the public Android app catalogue. Each record retains its actual evidence level. Some X references were not reconfirmed from the current homepage; one may be supported by a dated article. A catalogue listing is not a fresh verification. Do not erase these distinctions when using this dataset for retrieval or training. Decentralized networks can have multiple contributors; an account is not necessarily a network’s sole representative.

This is not a live news feed, an investment recommendation, a proof of factual truth, or a guarantee against phishing. Sites and handles can change. Recheck the current original source before acting. No user account data, private backend data, API keys or wallet data is included.

## Reuse
The repository’s authored code and compilation are MIT-licensed. External websites, trademarks and linked works retain their owners’ rights; no rights over those works are granted. The Samsung promotional screenshots are not required for dataset use and should not be bundled as training examples by default.
