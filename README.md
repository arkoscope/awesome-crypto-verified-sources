## How to use this directory

Open the official website first, compare the complete hostname and follow its own links. An official source identifies the speaker; it does not independently prove every claim. An account or website can be compromised. Never supply a recovery phrase or private key to read news.

The X handles below were present in our reviewed public Android catalogue. **✓** means the official homepage linked to that handle during this check; **↻** means the catalogue reference is retained but its link was not reconfirmed by the homepage extraction. A blocked fetch is not evidence that a source is fraudulent. Recheck ↻ references on the official site before using them for automated news.

## Verification and corrections

1. Match the project identity to its official domain; do not rely on a search-ad ranking, logo or paid verification badge.
2. Record the primary page that links to a social account or documentation. Preserve the check date.
3. Verify each news item separately, including publication date, exact source URL, and a restrained factual summary. Distinguish the project’s statement from an independently established fact.
4. Hold uncertain or changed links for review. Do not silently replace a handle with a similar-looking one.
5. Propose a correction with the first-party proof URL. No private messages, account tokens, user records or proprietary engine code belong in this repository.

`sources.json` is the machine-readable public subset. It intentionally excludes private catalogues, production credentials, financial records and proprietary application code. The directory does not scrape X or connect to an application backend.
